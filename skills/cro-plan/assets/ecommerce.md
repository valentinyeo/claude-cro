# E-commerce CRO Template

Industry template for online retail businesses. Applies to DTC brands, online
marketplaces, Shopify stores, subscription boxes, and any site selling physical
or digital products directly to consumers.

---

## Key Conversion Goals

| Goal | Priority | Typical Page |
|------|----------|-------------|
| Purchase completion | P0 | PDP -> Cart -> Checkout |
| Add to cart | P0 | Product detail page, category page |
| Checkout completion | P0 | Checkout flow |
| Average order value increase | P1 | Cart, PDP, checkout |
| Email/SMS list signup | P1 | Homepage, popup, footer |
| Account creation | P2 | Checkout, post-purchase |
| Wishlist/save for later | P2 | PDP, category page |

## Primary Metrics

| Metric | Definition | Benchmark (Median) | Top Performer |
|--------|------------|--------------------|---------------|
| Add-to-cart rate | Sessions with ATC event / total sessions | 8-10% | 12-15% |
| Cart-to-checkout rate | Sessions reaching checkout / sessions with ATC | 40-50% | 60-70% |
| Checkout completion rate | Purchases / sessions reaching checkout | 45-55% | 65-75% |
| Overall conversion rate | Purchases / total sessions | 1.5-2.5% | 3.5-5% |
| Average order value (AOV) | Total revenue / number of orders | Varies by vertical | +15-25% via upsell |
| Revenue per visitor (RPV) | Total revenue / unique visitors | Varies by vertical | Key compound metric |
| Cart abandonment rate | Carts created - purchases / carts created | 65-75% | 50-60% |
| Return visitor purchase rate | Returning visitors who purchase / all returning visitors | 3-5% | 8-12% |

## Common CRO Patterns for E-commerce

1. **Urgency and scarcity** -- "Only 3 left in stock", countdown timers for
   sales, "X people viewing this now." Must be authentic or risk trust damage.
   Real inventory data drives the strongest results.

2. **Reviews and ratings** -- Star ratings on PDP and category pages, review
   photos, verified buyer badges. Products with 10+ reviews convert 2-3x
   higher than products with zero reviews.

3. **Free shipping threshold** -- "Free shipping on orders over $75" with a
   progress bar in the cart. Increases AOV by 10-20% when threshold is set
   15-25% above current AOV.

4. **Abandoned cart recovery** -- 3-email sequence: reminder (1 hour), social
   proof (24 hours), discount (48 hours). Recovers 5-15% of abandoned carts.

5. **Product recommendations** -- "Frequently bought together", "Complete the
   look", "Customers also bought." Algorithmic or curated. Can increase AOV
   by 10-30%.

6. **One-click upsell (post-purchase)** -- After checkout, offer a
   complementary product at a discount. No re-entering payment info. 5-15%
   of customers accept.

7. **Guest checkout** -- Mandatory account creation is the #1 reason for
   checkout abandonment after price. Guest checkout with optional post-
   purchase account creation is best practice.

8. **Visual search and filters** -- Color swatches, size filters, and visual
   filtering on category pages reduce browsing friction and increase PDP
   visits.

## Quick Win Checklist

- [ ] Add trust badges (payment icons, security, guarantee) near Add to Cart button
- [ ] Display shipping cost and estimated delivery date on PDP (not just at checkout)
- [ ] Add "Free returns" messaging near the buy button if applicable
- [ ] Show review count and star rating in category page product cards
- [ ] Add a free shipping progress bar in the cart
- [ ] Enable guest checkout if it requires account creation
- [ ] Add urgency to limited-stock items with real inventory counts
- [ ] Make the Add to Cart button sticky on mobile
- [ ] Add product image thumbnails in the cart page
- [ ] Display "Frequently bought together" on PDP with one-click bundle add
- [ ] Reduce checkout form fields to the minimum required for shipping
- [ ] Add express payment options (Apple Pay, Google Pay, Shop Pay) at the top of checkout

## Recommended Test Ideas

| Test | Hypothesis | ICE Estimate |
|------|-----------|--------------|
| PDP: add video to product gallery | Product video will increase ATC rate because it reduces uncertainty about the product | 6.7 |
| Cart: free shipping threshold bar | Shipping threshold progress bar will increase AOV because it motivates customers to add items | 7.3 |
| Checkout: 1-page vs multi-step | Single-page checkout will increase completion rate because it reduces perceived steps | 6.0 |
| PDP: sticky ATC on mobile | Sticky ATC on mobile will increase ATC rate because users can add at any scroll position | 7.7 |
| Cart: cross-sell recommendations | "Complete the look" in cart will increase AOV because of impulse accessory purchases | 6.3 |
| PDP: review photos section | Displaying customer photos will increase ATC rate because user-generated content builds trust | 6.0 |
| Category: quick-view modal | Quick-view product modal will increase PDP visits and ATC because it reduces browsing friction | 5.7 |
| Checkout: express payments first | Showing Apple Pay/Google Pay before the form will increase checkout completion because it reduces perceived effort | 7.0 |
