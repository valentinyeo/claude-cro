# Generic CRO Template

Fallback template for sites that do not fit neatly into SaaS, E-commerce,
Local Service, Lead Generation, or Subscription categories. This template
focuses on universal conversion principles that apply to any website type:
clear value propositions, strong CTAs, trust signals, low friction, fast
loading, and mobile-first design.

Use this template for portfolios, informational sites, non-profit sites,
community platforms, media sites with conversion goals, hybrid business models,
or any site where the industry-specific templates do not apply.

## Key Conversion Goals

Identify the primary conversion action for the specific site. Common
universal conversions:

| Goal Type | Examples | Priority |
|-----------|---------|----------|
| Primary action | Contact, sign up, download, purchase, donate, subscribe | P0 |
| Secondary action | Email list, follow social, share content, create account | P1 |
| Engagement | Read more, watch video, use tool, explore section | P2 |
| Micro-conversion | Scroll depth, time on page, return visit, save/bookmark | P3 |

## Primary Metrics

| Metric | Definition | General Benchmark | Top Performer |
|--------|------------|-------------------|---------------|
| Primary conversion rate | Conversions / sessions | 1-3% | 5-10% |
| Goal completion rate | Goal completions / sessions (GA4) | 2-5% | 8-15% |
| Bounce rate | Single-page sessions / total sessions | 40-60% | 25-35% |
| Pages per session | Avg. pages viewed per session | 2-3 | 4-6 |
| Time on site | Avg. session duration | 1-2 min | 3-5 min |
| Return visitor rate | Returning sessions / total sessions | 20-30% | 35-50% |
| Mobile conversion rate | Mobile conversions / mobile sessions | 50-70% of desktop | 80-100% of desktop |

## Common CRO Patterns (Universal)

1. **Clear value proposition** -- Within 5 seconds, any visitor should
   understand: what you offer, who it is for, and why they should care. Test
   by showing the page to someone unfamiliar with the brand for 5 seconds,
   then asking them to describe what the site does.

2. **Strong primary CTA** -- One clear, prominent call-to-action per page
   section. Action-oriented text, high contrast, above the fold. The CTA
   should answer "What do I do next?" without ambiguity.

3. **Trust signals** -- People convert when they trust. At minimum: real
   contact information, testimonials or reviews, professional design, secure
   connection. The specific trust signals depend on the business type, but
   some form of credibility proof is always needed.

4. **Low friction** -- Every additional step, field, click, or second of
   loading reduces conversions. Audit every interaction between landing and
   converting. Remove anything that does not directly contribute to the
   conversion decision.

5. **Fast loading** -- Page speed affects both SEO and conversions. Target
   under 3 seconds for LCP. Optimize images, defer non-critical scripts,
   minimize third-party resources. Mobile speed is especially critical.

6. **Mobile-first** -- Design for mobile first, then enhance for desktop.
   Over 50% of web traffic is mobile, and mobile conversion rates are
   typically 40-60% lower than desktop. Closing this gap is high-ROI.

7. **Objection handling** -- Identify the top 3-5 reasons visitors do NOT
   convert, then address them proactively on the page. FAQ sections, guarantee
   messaging, comparison tables, and risk reversal all serve this purpose.

8. **Cognitive ease** -- Simple language, clear structure, familiar patterns,
   consistent design. The brain processes familiar things faster. Use
   conventional layouts, standard button styles, and expected navigation
   patterns.

## Quick Win Checklist

- [ ] Ensure the headline clearly communicates the value proposition (specific, not vague)
- [ ] Make the primary CTA visible above the fold on both desktop and mobile
- [ ] Add at least one trust signal near the primary CTA (testimonial, badge, guarantee)
- [ ] Reduce any form to the minimum number of fields necessary
- [ ] Fix mobile usability issues (tap targets, font size, horizontal scroll)
- [ ] Compress and lazy-load images below the fold
- [ ] Add a clear contact method (phone, email, or chat) visible on every page
- [ ] Change generic CTA text ("Submit", "Click Here") to specific action text
- [ ] Add social proof somewhere above the fold (review count, customer logos, testimonial)
- [ ] Ensure navigation does not have more than 7 primary items (cognitive load)

## Recommended Test Ideas

| Test | Hypothesis | ICE Estimate |
|------|-----------|--------------|
| Headline: specific benefit vs current headline | A specific, benefit-focused headline will reduce bounce rate because visitors immediately understand the value | 7.0 |
| CTA: personalized text vs generic text | First-person CTA ("Get My Free X") will outperform third-person ("Get Your Free X") because it creates ownership | 6.7 |
| Above fold: with vs without social proof | Adding a testimonial or review count above the fold will increase conversions because trust is established earlier | 7.3 |
| Page layout: long-form vs short-form | The correct length depends on traffic temperature -- test to find the right balance for this audience | 5.7 |
| Form: fewer fields vs current fields | Reducing form fields will increase submissions because each removed field reduces friction | 7.7 |
| Trust: with guarantee vs without | Adding a money-back or satisfaction guarantee will increase conversions because it reverses risk | 6.3 |
| Navigation: simplified vs current | Reducing navigation options on conversion pages will increase conversions because it reduces exit points | 6.0 |
| Mobile: sticky CTA vs static | A sticky mobile CTA will increase conversions because the action is always accessible regardless of scroll position | 7.3 |

## Tool Recommendations

| Category | Recommended | Why |
|----------|-------------|-----|
| Analytics | GA4 (free), Plausible, Fathom | Understand traffic, behavior, and conversions |
| A/B Testing | VWO, Google Optimize alternatives, Optimizely | Test hypotheses with statistical rigor |
| Heatmaps | Microsoft Clarity (free), Hotjar | See where users click, scroll, and get stuck |
| Page Speed | Google PageSpeed Insights, GTmetrix | Identify and fix speed bottlenecks |
| Forms | Typeform, Tally (free), native forms | Low-friction form experiences |
| Live Chat | Tidio, Crisp, Tawk.to (free) | Capture questions and convert undecided visitors |
| Surveys | Hotjar Surveys, Google Forms | Understand WHY visitors do or do not convert |
| Tag Management | GTM (free) | Manage all tracking from one place without code deploys |
