# Proven CRO Tests: B2B, SaaS & Consulting Landing Pages

A curated database of A/B tests with documented results for B2B websites,
SaaS platforms, consulting firms, and lead generation landing pages. Use these
as high-confidence test ideas when auditing service-based and lead-gen properties.

**How to use this database:**
- Reference tests by ID (e.g., `B2B-001`) in audit reports and test plans.
- Use the ICE scores as starting points — adjust based on the specific site context.
- Tests marked with higher confidence have been replicated across multiple sites.
- "Avg. Lift" is the median observed effect; actual results vary by site.

## Hero Section & Above-the-Fold Tests

### B2B-001: Benefit-Driven Headline vs. Feature-Driven

| Field | Value |
|-------|-------|
| **Element** | Hero headline |
| **Page** | Landing page / Homepage |
| **Control** | Feature-focused headline ("AI-Powered CRM Platform") |
| **Variant** | Benefit-focused headline ("Close 3x More Deals Without Hiring More Reps") |
| **Avg. Lift** | +21–35% conversion rate |
| **Confidence** | Very High — MECLABS research; replicated across 100+ landing pages |
| **ICE Score** | I: 8 · C: 9 · E: 9 → **8.7** |
| **Notes** | Specificity matters — include numbers, timeframes, or concrete outcomes |
| **Sources** | MECLABS headline studies; Unbounce conversion benchmark data; CXL Institute |

**Why it works:** Visitors make stay-or-leave decisions in 3–5 seconds.
Benefit-driven headlines immediately answer "What's in it for me?" while
feature-driven headlines force visitors to translate features into benefits
themselves — a cognitive step many won't take.

### B2B-002: Single CTA vs. Multiple CTAs

| Field | Value |
|-------|-------|
| **Element** | Call-to-action strategy |
| **Page** | Landing page |
| **Control** | Multiple CTAs (demo, trial, contact, learn more) |
| **Variant** | Single, focused CTA repeated throughout the page |
| **Avg. Lift** | +32% conversion rate |
| **Confidence** | Very High — Unbounce benchmark: pages with 1 CTA convert 32% higher |
| **ICE Score** | I: 8 · C: 9 · E: 9 → **8.7** |
| **Notes** | If you must have 2 CTAs, make one clearly primary and one secondary (ghost button) |
| **Sources** | Unbounce Conversion Benchmark Report; Instapage landing page data |

**Why it works:** Multiple CTAs create decision paralysis (Hick's Law). Each
additional choice divides attention and increases cognitive load. A single CTA
provides a clear path and eliminates the "which should I click?" hesitation.

## Form Optimization Tests

### B2B-006: Reduced Form Fields

| Field | Value |
|-------|-------|
| **Element** | Lead capture form |
| **Page** | Landing page / Contact page |
| **Control** | Long form with 7+ fields (name, email, phone, company, title, size, message) |
| **Variant** | Short form with 3–4 fields (name, email, company, and one qualifying question) |
| **Avg. Lift** | +20–120% form submissions |
| **Confidence** | Very High — Expedia case study: removing one field = +$12M/year |
| **ICE Score** | I: 9 · C: 9 · E: 8 → **8.7** |
| **Notes** | Trade-off: fewer fields = more leads but potentially lower quality. Consider progressive profiling |
| **Sources** | HubSpot form research; Unbounce data; Expedia case study |

**Why it works:** Each additional form field adds friction and perceived effort.
Reducing from 11 to 4 fields can increase conversions by 120% (HubSpot).
Missing fields can be collected through progressive profiling in nurture
sequences.

### B2B-007: Multi-Step Form vs. Single Long Form

| Field | Value |
|-------|-------|
| **Element** | Form architecture |
| **Page** | Landing page / Demo request |
| **Control** | Single long form showing all fields at once |
| **Variant** | Multi-step form (3 steps) with progress bar, starting with easiest question first |
| **Avg. Lift** | +15–40% form completion |
| **Confidence** | High — exploits commitment/consistency bias (Cialdini) |
| **ICE Score** | I: 8 · C: 8 · E: 6 → **7.3** |
| **Notes** | Start with low-commitment questions. Ask for email in step 2+. Show progress indicator |
| **Sources** | Klientboost case studies; CXL multi-step form experiments |

**Why it works:** Multi-step forms leverage the commitment and consistency
principle: once someone starts, they're more likely to finish. The initial
easy question (e.g., "What are you looking for?") gets micro-commitment
before asking for personal info.

### B2B-008: Inline Validation vs. Submit-Then-Error

| Field | Value |
|-------|-------|
| **Element** | Form validation UX |
| **Page** | Any page with forms |
| **Control** | Validation errors shown only after form submission |
| **Variant** | Real-time inline validation with green checkmarks for valid fields and helpful error messages |
| **Avg. Lift** | +22% form completion rate |
| **Confidence** | High — Luke Wroblewski form design research |
| **ICE Score** | I: 6 · C: 8 · E: 6 → **6.7** |
| **Sources** | Luke Wroblewski form design studies; Baymard form usability |

**Why it works:** Post-submit errors create frustration and confusion. Inline
validation provides immediate feedback, confirms correct input, and lets users
fix errors one at a time rather than facing a wall of error messages.

### B2B-009: Contextual Form Labels (Above-Field vs. Placeholder)

| Field | Value |
|-------|-------|
| **Element** | Form field labels |
| **Page** | Any page with forms |
| **Control** | Placeholder-only labels (text inside the field that disappears on focus) |
| **Variant** | Persistent labels above fields (or floating labels that animate above on focus) |
| **Avg. Lift** | +10–18% form completion |
| **Confidence** | High — Baymard: placeholder-only labels cause usability issues for 50%+ of users |
| **ICE Score** | I: 5 · C: 8 · E: 9 → **7.3** |
| **Sources** | Baymard form label research; Nielsen Norman Group |

**Why it works:** Placeholder text disappears when a user starts typing, forcing
them to remember what the field asked for. This is especially problematic for
longer forms, users with cognitive disabilities, and anyone who tab-navigates.

## CTA Optimization Tests

### B2B-010: Action-Oriented CTA Copy

| Field | Value |
|-------|-------|
| **Element** | CTA button text |
| **Page** | Landing page / Pricing page |
| **Control** | Generic CTA ("Submit", "Click Here", "Learn More") |
| **Variant** | Value-oriented, first-person CTA ("Start My Free Trial", "Get My Custom Quote", "See How It Works") |
| **Avg. Lift** | +20–40% click-through rate |
| **Confidence** | Very High — one of the most consistently winning test patterns |
| **ICE Score** | I: 7 · C: 9 · E: 10 → **8.7** |
| **Notes** | First-person ("my") outperforms second-person ("your") by ~24% (Unbounce) |
| **Sources** | Unbounce CTA data; GoodUI pattern research; CXL Institute |

**Why it works:** "Submit" tells users what they're doing (submitting a form).
"Get My Free Audit" tells users what they're getting. Value-focused CTAs
reframe the action from an effort (submit) to a reward (get).

---

### B2B-011: CTA Button Contrast & Size

| Field | Value |
|-------|-------|
| **Element** | CTA button visual design |
| **Page** | Landing page |
| **Control** | CTA blends with page design (low contrast, similar to other elements) |
| **Variant** | High-contrast CTA in a color not used elsewhere on the page, 20%+ larger than surrounding elements |
| **Avg. Lift** | +15–30% click-through rate |
| **Confidence** | High — GoodUI Contrast Pattern; Von Restorff isolation effect |
| **ICE Score** | I: 6 · C: 8 · E: 10 → **8.0** |
| **Sources** | GoodUI patterns; CXL button design research |

**Why it works:** The Von Restorff (isolation) effect states that items that
stand out from their surroundings are more likely to be noticed and remembered.
A CTA that visually "pops" draws the eye and guides action.

### B2B-012: Reducing CTA Friction with Reassurance Text

| Field | Value |
|-------|-------|
| **Element** | CTA microcopy |
| **Page** | Landing page / Signup page |
| **Control** | CTA button only ("Start Free Trial") |
| **Variant** | CTA button + friction-reducing microcopy below ("No credit card required · Cancel anytime · 14-day free trial") |
| **Avg. Lift** | +15–25% conversion rate |
| **Confidence** | High — addresses top objections at the decision point |
| **ICE Score** | I: 7 · C: 8 · E: 10 → **8.3** |

objections at the decision point directly increases conversion.

## Pricing Page Tests

### B2B-013: Highlighted Recommended Plan

| Field | Value |
|-------|-------|
| **Element** | Pricing plan design |
| **Page** | Pricing page |
| **Control** | All plans displayed equally |
| **Variant** | Middle/target plan visually highlighted with "Most Popular" or "Recommended" badge, slightly larger card, different background color |
| **Avg. Lift** | +15–25% selection of target plan; +10–18% overall pricing page conversion |
| **Confidence** | High — anchoring effect + social proof ("most popular") |
| **ICE Score** | I: 7 · C: 8 · E: 9 → **8.0** |
| **Sources** | CXL pricing page research; SaaS pricing optimization studies |

**Why it works:** Decision fatigue is a conversion killer on pricing pages.
Highlighting a recommended plan reduces the evaluation effort (from "which plan
is right for me?" to "should I go with the recommended one?") and leverages
the default effect — people tend to choose the pre-selected option.

---

### B2B-014: Decoy Pricing (Price Anchoring)

| Field | Value |
|-------|-------|
| **Element** | Pricing structure |
| **Page** | Pricing page |
| **Control** | Two plans: Basic ($19/mo) and Pro ($49/mo) |
| **Variant** | Three plans: Basic ($19/mo), Pro ($49/mo, highlighted), Enterprise ($129/mo) — with Enterprise making Pro look like great value |
| **Avg. Lift** | +20–30% Pro plan selection |
| **Confidence** | High — Dan Ariely's decoy effect research |
| **ICE Score** | I: 7 · C: 8 · E: 9 → **8.0** |
| **Sources** | Ariely "Predictably Irrational"; CXL pricing experiments |

**Why it works:** The decoy (Enterprise) isn't meant to sell — it's meant to
make the target plan (Pro) look like a great deal by comparison. This
asymmetric dominance effect consistently shifts choice toward the target plan.

### B2B-015: Annual vs. Monthly Toggle (Annual Default)

| Field | Value |
|-------|-------|
| **Element** | Billing period selection |
| **Page** | Pricing page |
| **Control** | Monthly pricing displayed by default |
| **Variant** | Annual pricing displayed by default with "Save 20%" badge, monthly available via toggle |
| **Avg. Lift** | +15–25% annual plan selection; +30–50% LTV increase |
| **Confidence** | High — default effect + savings framing |
| **ICE Score** | I: 8 · C: 8 · E: 9 → **8.3** |
| **Sources** | SaaS pricing benchmarks; ProfitWell retention data |

**Why it works:** Defaults are powerful — most users accept the pre-selected
option (default bias). Annual defaults increase commitment length, reduce churn,
and improve LTV. The savings badge provides rational justification for the
annual choice.

## Page Structure & Layout Tests

### B2B-019: Long-Form vs. Short-Form Landing Page

| Field | Value |
|-------|-------|
| **Element** | Page length / information architecture |
| **Page** | Landing page |
| **Control** | Short landing page (hero + form + 3 bullet points) |
| **Variant** | Long-form page (hero + features + benefits + social proof + FAQ + multiple CTAs) |
| **Avg. Lift** | Long-form wins for complex/expensive products (+20–40%); short-form wins for simple/free offers |
| **Confidence** | High — depends on offer complexity and price point |
| **ICE Score** | I: 7 · C: 7 · E: 5 → **6.3** |
| **Notes** | Rule of thumb: the higher the price/commitment, the more information needed |
| **Sources** | Unbounce page length data; CXL long-form vs short-form research |

**Why it works:** For high-consideration B2B purchases ($1,000+/year), buyers
need to justify the decision to themselves and their team. Long-form pages
provide the ammunition for internal buy-in. For free trials or low-commitment
CTAs, shorter pages reduce distraction.

### B2B-020: Dedicated Landing Pages vs. Homepage Traffic

| Field | Value |
|-------|-------|
| **Element** | Traffic destination |
| **Page** | Campaign landing page vs. homepage |
| **Control** | Sending ad/email traffic to the homepage |
| **Variant** | Dedicated landing page matching the ad's message, audience, and single CTA |
| **Avg. Lift** | +25–50% conversion rate |
| **Confidence** | Very High — message match is a foundational CRO principle |
| **ICE Score** | I: 9 · C: 9 · E: 5 → **7.7** |
| **Sources** | Unbounce benchmark data; Instapage personalization studies |

**Why it works:** Homepages serve multiple audiences with multiple CTAs.
Dedicated landing pages maintain "message match" (ad → page → CTA all aligned)
and eliminate navigation distractions, keeping visitors on a single conversion path.

### B2B-021: Removing Navigation on Landing Pages

| Field | Value |
|-------|-------|
| **Element** | Page navigation |
| **Page** | Landing page |
| **Control** | Full site navigation visible on landing page |
| **Variant** | Navigation removed or minimized (logo only, no menu) |
| **Avg. Lift** | +10–30% conversion rate |
| **Confidence** | High — fewer exit paths = higher conversion |
| **ICE Score** | I: 6 · C: 8 · E: 10 → **8.0** |
| **Sources** | Unbounce attention ratio research; VWO case studies |

**Why it works:** Every navigation link is an exit opportunity. Unbounce calls
this the "attention ratio" — the ratio of things you can do on a page to things
you should do. Landing pages should have a 1:1 attention ratio.

### B2B-022: Exit-Intent Popup with Value Offer

| Field | Value |
|-------|-------|
| **Element** | Exit-intent overlay |
| **Page** | Landing page / Pricing page |
| **Control** | No exit-intent mechanism |
| **Variant** | Exit-intent popup with relevant offer (free guide, discount, consultation, or alternative CTA) |
| **Avg. Lift** | +5–15% lead recovery from abandoning visitors |
| **Confidence** | Medium-High — 2–5% of exiting visitors engage with well-designed exit popups |
| **ICE Score** | I: 6 · C: 7 · E: 7 → **6.7** |
| **Notes** | Must provide value, not just repeat the same CTA. Mobile: use scroll-triggered instead of exit-intent |
| **Sources** | OptinMonster exit popup data; Sumo lead capture benchmarks |

**Why it works:** Exit-intent gives you a second chance with visitors who've
decided to leave. By offering something different (a lower-commitment CTA like
a guide download vs. a demo request), you capture leads who aren't ready for
the primary conversion but are interested enough to engage.
