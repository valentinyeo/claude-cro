# Evals: does the pack beat plain Claude?

Scored with `claude plugin eval`, once with the pack and once without (`--ablation with-without`), 3 runs per case.

## Cases

| Case | What the agent gets | Score |
|------|---------------------|-------|
| `defects-<site>` | A snapshot of the site with 5 obvious defects planted: a "Submit" CTA linking to `#`, the headline "Welcome to our website", a 9-field required form, a fake urgency banner, and the Pro plan priced $49 and $79 | Share of planted defects named in the answer |
| `defects-<site>.subtle` | The same snapshot with 5 subtle defects: placeholder-only inputs, an unbacked "Trusted by 10,000+ teams", a pre-ticked partner opt-in, a $25 setup fee in 10px grey text, and a money-back guarantee contradicted by "All sales are final" | Same |
| `defects-<site>.blind` | An independent snapshot with 5 blind defects: a guide-download CTA leading to sales, a blaming email error, an anonymous testimonial beside the primary CTA, a 12-month commitment disclosed only in the footer, and an image-only hero headline with empty alt | Same |
| `winner` | 121 published A/B tests with a clear result (every loss, and every win with 95%+ published confidence), shown as A and B in a seeded random order, without company or lift. The records are removed from the pack copy (`stage.py --holdout`) | Share of winners called right. A coin flip scores 50% |

The blind tier was authored without opening the pack's skills, agents or docs; it does not reuse the ten existing defects. Each tier is generated independently from the clean snapshot, not layered on another tier. All blind evidence is in the HTML (including inline image markup); no live destination or image fetch is needed.

Every defect answer also ends with a JSON list of `{problem, quote}`. `check.py` counts how many quotes really appear on the page.

The agents get Read, Glob, Grep and Skill only, no Bash or web: the pages are local snapshots and the live sites are not reachable from cloud runs.

## Files

- `fixtures/<site>.clean.html`: rendered snapshots (`tools/snapshot.py`). `*.planted.html`, `*.subtle.html`, `*.blind.html`: generated by `tools/plant.py`.
- `answer-keys/*.json`: what was planted and the pattern that counts as finding it. The eval graders use the same patterns.
- `tools/make_cases.py`, `tools/make_winner.py`: generate the cases, `holdout.txt` and `answer-keys/winner.json`.
- `scores/<label>.runs.json`: every run's final answer. `scores/<label>.json`: the summary. `scores/latest.json`: what CI checks.
- `floor.json`: the minimum with-pack scores CI accepts.

## Run

```
python evals/tools/plant.py && python evals/tools/make_cases.py && python evals/tools/make_winner.py
python evals/tools/stage.py /tmp/cro-stage --holdout evals/holdout.txt
cd /tmp/cro-stage && claude plugin eval . --scaffold --trust-plugin --ablation with-without --runs 3 -j 8 --keep-temp --threshold 0 --json /tmp/eval.json
cd - && python evals/tools/collect.py /tmp/eval.json <label> --latest
python evals/tools/check.py answer-keys
python evals/tools/check.py results
```

`--keep-temp` is needed: `collect.py` reads each run's final answer from its kept trace. Delete the kept `/tmp/claude-eval-*` folders afterwards.

CI (`evals` job) rebuilds every generated file and fails if one differs, checks each answer key against its page, recomputes every committed score from the saved answers, and fails if a with-pack score is below the floor.

`check.py answer-keys` checks all three tiers, exact snippet presence, clean-page regex false positives, and generated grader parity without consulting pack evidence. `check.py fixtures` additionally checks the winner evidence. Scores report `blind_recall` separately from `defect_recall` and `subtle_recall`; quote accuracy includes all tiers. The historical scores below predate the blind tier, so its recall is null until new runs are collected; no blind score floor is claimed yet.

## Results (2026-10-17, 3 runs per case and arm)

| Score | Plain Claude | Pack before fixes | Pack after fixes |
|-------|-------------:|------------------:|-----------------:|
| Obvious defects found | 100% | 100% | 100% |
| Subtle defects found | 82% | 84% | **100%** |
| Quotes really on the page | 100% | 100% | 100% |
| Test winners called right (coin flip 50%) | 74-75% | 75% | 75% |
| Runs where the pack fired | n/a | 0 of 21 | 18 of 21 (every page review, no winner run) |

Plain Claude is the without arm of each run (before: 82% subtle, 74% winners; after: 82%, 75%). Before the fixes the pack never fired, so its arm was plain Claude too. Plain Claude's only consistent miss was placeholder-only inputs.

Caveats: the subtle tier and the cro-page sweep were written in the same session, so that gain partly reflects teaching to the test. The obvious tier is too easy to separate the arms. On the winner set, always picking the changed version scores 84% (16 of 19 are wins), so beating 50% is not the bar: neither arm beats that simple rule, and the pack never fires on that prompt.

## Winner rerun (2026-10-23, 3 runs per arm)

The evidence database grew to 253 tests, so the winner set grew from 19 to 121 tests (83 losses, 38 wins). Only the winner case was rerun; `scores/after-winner121` keeps the 2026-10-17 page review runs and adds the new winner runs, and `scores/latest.json` points at it.

| Score | Plain Claude | Pack |
|-------|-------------:|-----:|
| Test winners called right (coin flip 50%) | 65% | 66% |
| Runs where the pack fired | n/a | 3 of 3 |

Always picking the original page scores 69% on this set (83 of 121 changes lost), so neither arm beats that simple rule yet.
