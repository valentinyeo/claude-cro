Experiments: what we test next (5)

Every result above feeds these. Each one says what we believe, which results show the problem, how to run it at this site's traffic, and when to call it.

E1 · Critical · Setup, then baseline

Count every Book a Call click and booked call

Hypothesis

Because nothing measures visits or bookings today, we believe adding click and booking tracking will give a baseline that every later change can be judged against.

Evidence from

3. Tracking check, 4. Test readiness, 1. Site audit

How to run it
  1. Turn on Cloudflare Web Analytics for the Pages project (cookieless, no banner needed)
  2. Fire an event on every Book a Call click with the page name, and add ?src=<page> to the calendar link
  3. Each week, write down booked calls from Google Calendar
  4. Pause the Endless Testing headline test so all visitors see one version
Book a Call clicks per 100 visits, booked calls per weekwhat we measure
4 weeks of baselinehow long
Done when 4 full weeks are recordedwhen we call it

E2 · High · Ship + before/after, checked by synthetic visitors

First screen: free 30-min call, price and the inne result

Hypothesis

Because buyers could not find a price, doubted the claims and did not know what the call is, we believe showing the free 30-minute call, the day rate and the +14.6% inne result on the first screen will raise Book a Call clicks for product and growth leads.

Evidence from

1. Site audit, 7. Synthetic visitor swarm, 5. Persona walk-throughs, 8. Fix wireframe

How to run it
  1. Build the wireframe as a real page on a Cloudflare preview link
  2. Send 25 synthetic visitors to today's page and 25 to the preview; compare how many reach booking and what stops them
  3. Show the preview to 5 product or growth leads on a call and note where they hesitate
  4. Ship it and log the date

How we verify results at this traffic

Too few conversions for an A/B test means no single number proves a change. We stack weaker checks that point the same way:

  1. Rescore before and after: rerun the same tests (audit, 25 AI visitors, the two buyer walk-throughs) on the new page. The scores on this page must go up. Free or cheap, done in a day, but it shows the page got clearer, not that it sells more.
  2. Five real buyers on a call: show the new page to 5 product or growth leads and note where they hesitate. Five people find most usability problems.
  3. Count clicks, not only bookings: Book a Call clicks happen far more often than bookings, so a change shows up in clicks within weeks (needs E1 tracking first).
  4. Before and after on bookings: 4 weeks before vs 4 weeks after, with LinkedIn posting kept steady. At about 3 bookings a month only a large change is visible, so we treat it as a sanity check, not proof.
  5. Ask every new lead: one question on the booking form, "What made you book?". It tells us which change people noticed.
